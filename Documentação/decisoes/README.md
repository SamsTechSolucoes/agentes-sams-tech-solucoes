# Log de decisões

Registre aqui decisões **já tomadas** pelo Samuel (ou por ele confirmadas), uma por arquivo, para não reabrir o mesmo assunto.

## Padrão de nome

`AAAA-MM-DD-titulo-curto.md`

Exemplo: `2026-09-17-repo-agentes-somente-docs.md`

## Modelo

```markdown
# Título da decisão

- **Data:** AAAA-MM-DD
- **Status:** vigente | superada | pendente de confirmação
- **Decisor:** Samuel
- **Contexto:** 1 parágrafo
- **Decisão:** o que vale a partir de agora
- **Consequências:** o que os agentes devem / não devem fazer
- **Fora de escopo:** o que esta decisão não autoriza
```
