# Runbook — Instalar o app Grok Bot no PC do Samuel

**Quando:** o que está aberto é Cursor / Cloud Agent / Slack, e falta o app da equipe.  
**Quem:** Samuel (instalação). Engenheiro Principal só documenta.  
**PC:** Windows em `C:\Users\notebook\…`

## Pré-condições

- Cursor Pro já pago (Grok Bot incluso; sem segundo login).
- Ambientes Cursor já configurados — **não** reconfigurar.
- Cursor IDE pode ficar aberto ao mesmo tempo.

## Passos

1. Abrir https://cursor.com/download/bot
2. Baixar **Windows (x64)** (ou ARM64 se o PC for ARM).
3. Instalar → abrir **Grok Bot** no menu Iniciar.
4. **Get started** → autenticar no navegador com a conta do Cursor.
5. Abrir **Secretária SamsTech** (dia a dia) ou **SamsTech Engineer** (comando de engenharia).

Guia curto na raiz: `ABRIR-GROK-BOT.md`.
