# Religar WhatsApp Web — SÓ por CÓDIGO (sem QR)

**Destino autorizado:** contato pessoal de Samuel, mantido fora do Git.  
**Onde:** navegador do **Grok Bot** → Agent Computer → `web.whatsapp.com`

WhatsApp Web neste ambiente: **não usar QR**. Usar **vincular com número de telefone** (código de 8 dígitos).

---

## Samuel — religar agora (2–3 min)

1. No Grok, abra o **Agent Computer** do **SamsTech Engineer**.
2. No browser, vá em https://web.whatsapp.com  
   - Se pedir QR: na própria tela procure **"Vincular com número de telefone"** / **"Link with phone number"** / **"Conectar com número"**.
3. No celular WhatsApp:
   - **Aparelhos conectados** (ou Configurações → Aparelhos conectados)
   - **Conectar um aparelho**
   - Escolha **vincular com número** (não a câmera do QR)
4. Digite no celular o **mesmo número** da conta (DDI 55 + 81…).
5. No **computador do Grok** aparece um **código de 8 caracteres**.
6. Digite esse código no celular e confirme.
7. Espere a **lista de conversas** aparecer no Agent Computer.
8. Aviso no chat do Engineer: "WhatsApp religado por código — pode enviar a mensagem de abertura."

Se a tela do PC só mostrar QR e **não** tiver o link do código:
- Troque o idioma da página / role a tela / clique em “Precisa de ajuda para vincular?”
- Ou use outro browser no Agent Computer (Chrome → Edge) e tente de novo.
- Não peça ao bot para “escanear QR”.

---

## Colar no SamsTech Engineer (depois de religado OU para ele ajudar)

```
REGRA FIXA DESTE PROJETO:
- WhatsApp Web = somente vínculo por CÓDIGO (8 dígitos).
- QR code = PROIBIDO pedir / PROIBIDO insistir.

AGORA:
1) Abra web.whatsapp.com no Agent Computer.
2) Se estiver logado (lista de chats): abra o contato pessoal autorizado de Samuel e envie:
   "Olá Samuel — Engenheiro Principal online. Canal por código religado. Pode dar as diretrizes."
3) Se NÃO estiver logado:
   a) Na tela, clique em "Vincular com número de telefone" / "Link with phone number" (NÃO fique no QR).
   b) Mostre/descreva o código de 8 dígitos ao Samuel OU diga onde ele aparece.
   c) Aguarde Samuel confirmar no celular.
   d) Quando a lista de chats aparecer, envie a mensagem do passo 2.
4) Resposta obrigatória: ENVIADO | AGUARDANDO_CODIGO | BLOQUEIO:<o que a tela mostra>
```
