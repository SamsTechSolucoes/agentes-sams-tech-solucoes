# Abrir / baixar o app Grok Bot (não é o Cursor)

O **Cursor** (IDE no PC, `cursor.com/agents` e o `@cursor` no Slack) **não** é o app Grok Bot.  
São dois programas. A equipe **Secretária SamsTech**, **SamsTech Engineer**, etc. vive no **Grok Bot**.

Fonte oficial: [Get started with Grok Bot](https://cursor.com/docs/grok-bot/get-started)  
Download: [cursor.com/download/bot](https://cursor.com/download/bot)

## 1. Baixar no Windows (seu notebook)

1. No navegador, abra: **https://cursor.com/download/bot**  
   (ou no dashboard do Cursor: linha **Download Grok Bot**.)
2. Escolha o instalador:
   - **Windows (x64)** — a maioria dos PCs Intel/AMD
   - **Windows (ARM64)** — só se Configurações → Sistema → Sobre → Tipo de sistema disser ARM
3. Rode o instalador.
4. Abra **Grok Bot** no menu Iniciar (ícone próprio; não é o ícone do Cursor).
5. Tela inicial → **Get started** → entre **com a mesma conta do Cursor Pro**. Não existe login separado.
6. Volte para o app quando o navegador confirmar.

Celular (opcional): App Store → **Grok Bot** (iPhone, iOS 18+), mesma conta.

## 2. O que abrir depois do login

| Chat no Grok Bot | Para quê |
|---|---|
| **Secretária SamsTech** | Dia a dia (já validado no piloto) |
| **SamsTech Engineer** | Comando ao Engenheiro; execução continua no Cursor |

Cursor no PC **continua aberto** na pasta `SamsTechSolucoes-Agentes`. O Grok Bot fala; o Cursor (e o Cloud Agent) executa git/arquivos.

## 3. O que você já estava usando (e pode continuar)

| Canal | É Grok Bot? | Uso |
|---|---|---|
| Cursor no PC (IDE) | Não | Pasta, git, Agent local |
| `cursor.com/agents` | Não | Cloud Agent (esta conversa de engenharia) |
| Slack `@cursor` | Não | Dispara Cloud Agent |
| App **Grok Bot** | **Sim** | Conversar com Secretária / Engineer / equipe |

Os três primeiros **não substituem** o app. O Slack daqui chegou no Engenheiro via Cloud Agent — por isso parecia “Grok” e não era o app.

## 4. Plano e custo (não ligar extra)

Cursor **Pro** já inclui Grok Bot (cota semanal própria, não é o chat do IDE).  
Se a cota semanal acabar, o app pode oferecer **on-demand** (cobrança extra). **Não ligar** sem você decidir. Sem Skill/Routine ainda.

Se o login falhar: em Cursor, conferir se a conta não está em *Privacy Mode (Legacy)* — o Grok Bot exige armazenamento em nuvem. Documentação: [Plans and billing](https://cursor.com/help/grok-bot/plans).

## 5. Não é isto

- **grok.com** / app Grok da xAI no X — outra conversa, não é a equipe SamsTech.
- Reconfigurar Ambientes Cursor — **proibido** (já estão ok).
- Instalar de site não oficial.
